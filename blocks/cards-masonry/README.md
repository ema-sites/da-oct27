# cards-masonry

Custom **cards** block. Purpose: Text-first rounded white cards in 3+2 masonry grid, optional corner image.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card: body cell with eyebrow paragraph, H3 title, description, CTA link as the last paragraph | image cell (optional, rendered in the lower corner); cards lay out in rows of three, a trailing two or one stretch to full width.

## Supported variations

No variations.
