# quote-story

Custom **quote** block. Purpose: Centered customer testimonial with logo, heading, quote, attribution, CTA.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: logo image (optional), heading (optional), quotation paragraph(s); row 2: attribution (italic text becomes a citation) and an optional link-only paragraph such as "Read the story".
